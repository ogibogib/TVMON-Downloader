TVMON Download Manager

시작하기
압축본은 폴더 전체를 풀고 TVMON-Download-Manager.exe를 실행하세요.
Windows 10/11 64비트용입니다. B 브라우저 검증에는 해당 PC에 설치된 Google Chrome이 필요합니다.
영상 회차 주소와 저장 폴더를 입력한 뒤 '추가하고 시작'을 누릅니다.
진행 중 다른 주소를 추가하면 대기열에 들어가며 영상은 차례대로 다운로드합니다.
각 영상은 최대 8개 조각을 동시에 받습니다.
서버별 진행 중 작업 수를 기준으로 분배하고, 다른 서버의 조각이 먼저 끝나도 남은 조각으로 빈 작업 자리를 채웁니다.
남은 서버가 2개이면 보통 4개씩, 1개이면 최대 8개를 처리합니다. 한쪽의 남은 조각이 적으면 다른 쪽에 더 배정합니다.
남은 조각 자체가 8개보다 적으면 동시 작업 수가 줄어듭니다. 실제 속도는 영상 서버 응답과 저장 장치 상태에 따라 달라집니다.

다운로드 목록 메뉴
항목을 우클릭하면 작업 메뉴가 열립니다. Shift+F10 또는 메뉴 키로도 열 수 있습니다.
완료 영상은 '재생', TXT·ZIP은 '파일 열기'로 엽니다. 진행 중에는 '일시정지', 중단한 작업에는 '시작 / 이어받기'를 사용합니다.
메뉴에서 상세 진행, 저장 폴더 열기, 원본 주소 복사, 목록에서 제거도 실행할 수 있습니다. 여러 항목을 선택하면 적용 가능한 작업만 활성화됩니다.
원본 주소 복사는 다운로드 시작과 같은 도메인 선택 기준을 사용합니다. 영상은 현재 우선 접속 주소, TXT·ZIP은 현재 소설 접속 주소로 복사하며 여러 항목은 줄바꿈으로 구분합니다. 저장된 작업 식별자와 이어받기 기록은 유지합니다.
우클릭 메뉴 글꼴은 다운로드 목록과 같은 크기이며, 아이콘과 여백을 줄여 메뉴를 작게 표시합니다.

목록과 상세 진행 갱신
목록은 표시 값이 바뀐 행만 갱신하고, 순서나 필터가 바뀔 때만 행을 재배치합니다.
상세 진행 창이 닫혀 있으면 서버·작업자·조각 지도 등의 반복 그리기를 생략합니다. 다운로드 상태는 계속 수집하며 창을 다시 열면 최신 상태를 표시합니다.
화면 갱신 부담을 줄이는 개선으로, 실제 다운로드 속도는 영상 서버·피어·네트워크·저장 장치 상태에 따라 달라집니다.

콘텐츠 검색과 회차 일괄 추가
TVWIKI 영상 검색은 도메인 설정의 우선순위에 따라 TVWIKI 또는 tvmon1.com에 연결합니다.
연결에 실패하거나 검색 응답이 올바르지 않으면 다음 등록 도메인으로 자동 전환합니다.
여러 페이지를 읽던 중 전환하면 새 도메인의 첫 페이지부터 다시 검색해 결과 누락을 방지합니다.
정상적인 검색 결과가 0개인 경우에는 다른 도메인으로 전환하지 않습니다.
상단 '콘텐츠 검색' 탭에서 'TVWIKI' 또는 '뉴토끼'을 선택하고 작품 이름(예: 삼국지)을 입력해 검색하세요.
회차 선택과 Q 추가는 A 영상과 B 소설에서 사용할 수 있습니다. B 소설은 아래 TXT 안내를 참고하세요.
영상 주소, 저장 폴더 경로, 콘텐츠 검색어, 도메인 주소의 모든 직접 입력칸에 같은 한글 입력 처리를 적용합니다. 한글 조합 중 블록 커서를 글자 뒤의 얇은 세로 커서로 표시합니다.
영상 주소와 도메인 주소의 Enter 등록, 영상 주소의 우클릭 붙여넣기는 그대로 사용할 수 있습니다.
문장 중간 수정, 방향키, 선택, 붙여넣기를 지원하며 한글 조합을 강제로 확정하지 않습니다.
최근 검색 목록에는 검색 버튼이나 Enter로 실행한 검색어를 최근 순으로 최대 20개 저장합니다. 같은 검색어를 다시 사용하면 맨 위로 이동합니다.
최근 검색어를 선택하면 입력칸에 채우고 바로 검색합니다. 기록은 프로그램을 다시 열어도 유지됩니다.
최근 검색 목록 옆의 선택 삭제는 현재 선택된 검색어 한 개를, 전체 삭제는 모든 최근 검색 기록을 지웁니다. 삭제는 즉시 저장하며 검색 결과와 다운로드 작업은 유지합니다.
최근 검색 기록은 실행 파일 옆 data\jobs.json의 recent_searches 항목에 저장합니다. 기록이 없으면 삭제 버튼을 사용할 수 없습니다.
'다운로드' 탭과 '콘텐츠 검색' 탭을 한 창에서 전환할 수 있습니다.
탭을 전환해도 검색어, 카테고리 필터, 회차 선택과 썸네일을 유지합니다.
검색 결과에는 썸네일, 작품명, 분류를 표시합니다. 연도와 조회수는 사이트 검색 응답에 있을 때만 표시합니다.
사이트의 현재 제목 검색 방식을 사용합니다. 좋아요 수는 조회수로 표시하지 않습니다.
검색 결과를 클릭하면 오른쪽에 전체 회차를 첫 회차부터 표시합니다.
콘텐츠 목록 썸네일 오류는 최대 3회 자동으로 다시 받습니다. 계속 실패하면 상단 '콘텐츠 썸네일 다시 받기'를 누르세요.
회차 목록 썸네일은 한 번만 요청합니다. 실패하면 '이미지 없음'으로 표시하며 자동/수동 재시도는 하지 않습니다.
검색 결과가 여러 페이지이면 자동으로 전부 불러와 한 목록에 표시합니다.
검색 결과의 개수는 현재 페이지 개수가 아닌 전체 콘텐츠 개수입니다.
검색 결과 위 '카테고리' 드롭다운에서 드라마, 영화, 예능 등 실제 검색 결과에 있는 분류를 선택하세요.
'전체'를 선택하면 원래 검색 결과를 모두 표시합니다. 새 검색을 하면 필터는 '전체'로 돌아갑니다.
선택한 콘텐츠가 필터에서 제외되면 회차 선택도 해제하여 다른 콘텐츠의 회차를 추가하지 않도록 합니다.
Ctrl+클릭으로 여러 회차, Shift+클릭으로 연속 회차를 선택할 수 있습니다.
'선택 Q 추가': 선택한 회차를 다운로드 대기열에 넣습니다.
'전체 Q 추가': 해당 작품의 모든 회차를 대기열에 넣습니다.
'선택 다운로드': 선택한 회차를 대기열에 넣고 다운로드를 시작합니다.
이미 같은 저장 폴더의 작업 목록에 있는 회차(완료 포함)는 건너뜁니다.
Q에만 추가하면 정지된 대기열은 시작하지 않습니다. 실행 중인 대기열은 순서대로 이어집니다.
기존 작업을 다시 받으려면 매니저에서 해당 작업을 선택해 '시작 / 이어받기'를 누르세요.
탭을 전환해도 검색 조회와 기존 다운로드는 계속됩니다. 프로그램을 닫을 때 함께 정리합니다.
JPEG/PNG와 Windows WebP 코덱이 설치된 PC의 WebP 썸네일을 표시합니다.

B · 작품 검색과 소설 TXT 저장
'콘텐츠 검색' 탭에서 '뉴토끼'를 선택하면 현재 확인된 B 주소의 작품명 검색을 사용합니다.
B 주소가 없거나 주소 확인이 진행 중이면 먼저 접속을 확인한 뒤 같은 검색어로 이어서 검색합니다.
검색 결과가 여러 페이지이면 먼저 받은 결과부터 표시하고 나머지를 계속 불러옵니다. 모두 받은 뒤 전체 개수를 표시합니다.
왼쪽 목록에는 표지, 작품명, 실제 분류, 완결 표시와 사이트에 표시된 회차 수를 보여줍니다.
B 검색은 소설만 요청하고 표시합니다. B 카테고리는 소설로 고정하며 변경할 수 없습니다. A 영상의 카테고리는 기존처럼 선택할 수 있습니다.
작품을 선택하면 오른쪽에 분류, 상태, 표시 회차, 장르가 나옵니다. 완결 표시가 없으면 연재 중으로 추측하지 않습니다.
'사이트에서 열기'를 직접 누르면 기본 브라우저에서 선택한 작품 페이지를 엽니다.
소설 작품을 선택하면 사이트의 전체 목록을 확인하고 다운로드 가능한 회차만 번호순으로 표시합니다. 0화가 있으면 0화부터 표시합니다. 처음 100개 이후의 회차도 더보기 목록을 따라 확인합니다.
준비중 표시(isNotReady), 비활성화된 링크, 회차 주소가 없는 항목은 다운로드 목록과 ZIP 대상에서 제외합니다. 작품에 표시된 전체 회차 수에는 준비중 회차가 포함될 수 있으므로 다운로드 가능한 개수와 다를 수 있습니다.
회차 목록에는 회차/제목과 등록일이 나옵니다. Ctrl+클릭, Shift+클릭, 전체 선택을 사용할 수 있습니다.
'선택 TXT 저장'은 선택 회차를 기존 대기열에 등록하고 차례로 저장합니다. '선택 Q 추가'와 '전체 Q 추가'는 대기열 등록만 합니다.
'선택 TXT 저장' 옆의 '전체 ZIP으로 저장'은 현재 소설의 전체 회차를 대상으로 합니다. 선택한 회차 수와 관계없이 전체 목록을 사용합니다.
현재 저장 폴더의 대기열에 이미 완료된 TXT가 있으면 재사용하고, 빠진 회차/오류 회차만 하나씩 받습니다.
전체 회차를 한 번 순회한 뒤 실패한 회차만 최대 3회 더 재시도합니다. 재시도 대기 시간은 순서대로 3초, 10초, 30초입니다.
모든 다운로드 대상 TXT가 준비되면 '작품명 · 1~254화.zip'처럼 실제 첫/마지막 회차 번호가 포함된 이름으로 자동 압축합니다. 0화가 있으면 '0~19화'처럼 표시합니다.
검색 결과에서 완결 표시가 확인된 작품은 '작품명 · 1~254화 · 완결.zip'처럼 완결을 추가합니다. 완결 표시가 없으면 임의로 붙이지 않습니다. 긴 제목도 회차 범위와 완결 표시는 보존합니다.
파일 개수와 CRC 검증 후 완료로 표시합니다. 이전에 완성한 ZIP의 파일 이름은 자동으로 변경하지 않습니다.
압축 파일은 매니저의 현재 저장 폴더에 생성합니다. 같은 ZIP 이름이 있으면 번호를 붙여 보존합니다.
ZIP 작업이 새로 받는 TXT는 저장 폴더의 .tvmon-zip/작업ID 임시 폴더에 보관하며, ZIP 전체 검증 및 완료 기록 저장 후 자동 삭제합니다.
기존에 개별 저장한 TXT는 기본적으로 보관합니다. 검색 화면의 'ZIP 완료 후 원본 TXT 정리'를 선택했을 때만 해당 ZIP에 포함된 원본 TXT를 삭제합니다. 이 옵션의 기본값은 해제입니다.
정리할 TXT가 ZIP 안의 내용과 바이트 단위로 일치하는지 확인합니다. 압축 후 수정한 파일이나 ZIP 검증 실패 시 원본은 삭제하지 않습니다.
삭제된 TXT의 회차 행도 다운로드 목록에서 제거합니다. 최종 ZIP 행에는 전체 회차 수와 ZIP 파일이 남고, 보관한 원본 TXT 행은 유지합니다.
삭제 실패나 정리 중단 시 ZIP은 완료 상태로 보관하며 목록에 'TXT 정리 대기'를 표시합니다. 'TXT 정리 재시도'를 누르면 재다운로드 없이 정리를 다시 수행합니다.
ZIP 완료 기록을 먼저 저장한 뒤 정리하므로, 프로그램 종료 후에도 남은 정리를 이어갈 수 있습니다. 오류/일시정지한 다운로드의 임시 TXT는 유지합니다.
전체 ZIP 작업은 다운로드 탭에 별도 행으로 표시합니다. 전체 작업을 멈추려면 이 ZIP 행을 선택해 일시정지를 누르세요.
프로그램을 다시 연 뒤에는 ZIP 행의 '시작 / 이어받기'로 완료한 TXT를 재사용하며 나머지를 받습니다. 오류 시 자동 재시도가 켜져 있고 대기열이 실행 중이면 최종 오류 뒤에도 자동으로 이어받습니다.
3회 재시도 후에도 오류가 남으면 ZIP을 완료하지 않고 오류로 표시합니다. 오류 시 자동 재시도가 켜져 있으면 30초 후 재개하며, 꺼져 있으면 로그와 오류 회차를 확인해 주세요.
브라우저 인증이 필요하면 자동 재시도 대신 대기열을 멈춥니다. 오류 회차의 '브라우저 인증 열기'으로 검증을 완료하세요.
미완성 ZIP에 필요한 회차 작업은 단독으로 제거할 수 없습니다. ZIP 작업을 함께 선택하거나 먼저 제거해야 합니다.
이미 완성된 같은 전체 ZIP이 있으면 다시 받거나 중복 압축하지 않고 해당 작업을 선택합니다. 'ZIP 완료 후 원본 TXT 정리'를 선택하고 다시 누르면 기존 ZIP을 검증해 원본 정리만 수행합니다.
개별 TXT 저장은 매니저의 저장 폴더에 '작품명 · 회차 · 제목.txt'로 저장합니다. 본문 문단을 유지하는 UTF-8 형식이며 메뉴/광고는 넣지 않습니다.
같은 이름의 파일이 이미 있으면 (1), (2) 등을 붙여 기존 파일을 보존합니다. 같은 저장 폴더 대기열에 이미 있는 회차는 중복 등록하지 않습니다.
TXT 작업도 프로그램 재시작 후 보존합니다. 중단한 회차는 다시 시작할 때 본문을 새로 불러오며, 완료되지 않은 TXT를 완료 파일로 남기지 않습니다.
다운로드 항목을 우클릭한 뒤 '파일 열기'를 누르면 연결된 텍스트 편집기에서 읽을 수 있습니다.
회차 목록에서 인증이 필요하면 콘텐츠 검색 탭의 '브라우저 검증 열기'를 누르세요.
본문 인증이 필요하면 대기열 진행을 멈춥니다. 해당 작업을 선택하고 '브라우저 인증 열기'을 누르면 검증 후 같은 회차를 다시 저장합니다.
사이트에서 이용할 수 있는 본문만 저장하며, 로그인이나 이용 권한이 필요한 회차는 사이트에서 먼저 확인해야 합니다.
B 화면에는 다운로드 대상인 소설만 표시합니다.
접속 로그에는 회차 조회/본문 준비/저장 결과를 기록하며 소설 본문은 기록하지 않습니다.
A/B를 전환해도 입력한 검색어와 각 대상의 받은 결과, 필터, 작품/회차 선택, 받은 썸네일을 보존합니다.
검색 도중 A/B를 전환하면 진행 중인 검색 요청을 중단합니다. 돌아온 뒤 다시 검색하면 처음부터 확인합니다.
이 검색 결과 보존은 현재 프로그램 실행 중에 적용됩니다. 최근 검색어는 프로그램을 다시 열어도 유지됩니다.
자동 검색은 인증된 전용 Chrome의 숨김 페이지에서 결과 HTML만 읽습니다. 검색 결과 화면 전체를 매번 렌더링하지 않습니다.
추가 인증이 필요하면 검색창 옆의 '브라우저 검증 열기'를 직접 누르세요. 검증 후 같은 검색어로 이어서 검색합니다.
검색 결과 없음, 접속 오류, 검증 필요를 구분합니다. 중간 페이지가 실패하면 받은 결과와 전체 확인 실패를 함께 표시합니다.
B 검색 시작·페이지별 누적 개수·완료/실패도 기존 text-domain.log에 기록합니다.

A · 영상 사이트의 도메인 접속 순서
'도메인 설정' → 왼쪽 'TVWIKI' → '등록된 주소 관리'에서 주소 추가, 제거, 접속 순서 변경을 할 수 있습니다.
기본 순서는 https://tvmon1.com 다음 https://tvwiki52.net입니다.
'위로 / 아래로'로 우선순위를 바꾸면 즉시 저장하고 다음 접속부터 적용합니다.
도메인은 https://tvwiki52.net처럼 경로 없이 입력하세요. 접속 도메인은 하나 이상 필요합니다.
연결 실패나 서버 오류가 발생하면 다음 도메인으로 시도하며 영상 경로와 검색 조건은 유지합니다.
첫 도메인에서 성공하면 이후 도메인은 시도하지 않습니다.
검색, 회차 목록, 다운로드 정보 조회와 사이트 내부 이미지 주소에 적용합니다.
별도 영상 서버와 외부 이미지 서버의 주소는 그대로 사용합니다.
다운로드 상세 화면에는 현재 접속 순서의 첫 도메인을 우선 접속 주소로 표시합니다. 영상 정보도 이 도메인으로 우선 요청합니다.
작업 기록에는 영상 정보 접속 주소와 실제 영상 목록 서버를 표시합니다. HTTP 오류에는 실패한 서버 이름을 함께 표시합니다.
영상 파일을 제공하는 별도 서버 주소는 사이트의 응답을 따릅니다. 기존 작업과 이어받기 정보는 유지합니다.
등록한 도메인이 모두 실패하면 실패한 주소들을 화면에 표시합니다.

A 최신 주소 자동 확인
'최신 주소 확인' 버튼과 시작 시 자동 확인은 같은 순서로 동작합니다.
1. 도메인 접속 순서에 등록된 주소를 위에서부터 확인합니다. 성공하면 즉시 종료합니다.
2. 등록된 주소가 모두 실패하면 저장한 안내 URL(기본 https://tvwikiurl.net/)의 현재 안내 주소를 읽고 HTTP/HTML 이동을 따라 확인합니다.
3. 안내 주소도 실패하면 마지막 안내 도메인의 번호를 +1, +2, +3까지 최대 세 번 확인합니다.
   예: 안내 도메인이 tvwiki52.net이면 tvwiki53.net, tvwiki54.net, tvwiki55.net 순서입니다.
   안내 도메인에 숫자가 없거나 안내 주소를 읽지 못하면 번호를 추측하지 않고 실패로 처리합니다.
4. 모든 후보가 실패하면 접속 실패 이유를 표시하고 기존 목록을 보존합니다.
기본 주소(/)가 응답했지만 빈 화면 등으로 콘텐츠 홈페이지를 확인하지 못하면 같은 도메인의 /index.php를 한 번 더 확인합니다.
두 경로의 시도 결과는 별도 행으로 기록합니다. 정상 주소는 /index.php를 제외한 도메인만 저장합니다.
HTTPS 연결과 콘텐츠 홈페이지가 확인된 주소만 첫 번째로 저장합니다. 이미 등록된 주소는 중복 추가하지 않습니다.
현재 등록된 tvwiki53.net이 정상이면 안내 사이트의 52 주소를 다시 확인하지 않습니다.
'시작할 때 최신 주소 자동 확인'을 켜면 프로그램을 열 때 백그라운드에서 같은 확인을 수행합니다.
자동 확인 중에도 검색과 다운로드 화면을 사용할 수 있습니다.
확인 중인 주소는 하단 상태에 표시하고, 주소 확인 기록에는 단계별 주소와 확인 중/성공/실패 결과를 남깁니다.
안내 페이지의 성공은 다음 주소 안내를 확인했다는 뜻이며, 최종 정상 주소는 콘텐츠 홈페이지 확인으로 구분합니다.
긴 상세 내용은 가로 스크롤로 볼 수 있습니다. 기록은 다음 확인을 시작하면 새로 작성합니다.
도메인 뒤의 영상 경로와 검색 조건, 기존 작업/이어받기 정보는 그대로 유지됩니다.

B · 텍스트 사이트의 주소 확인
'도메인 설정' → 왼쪽 '뉴토끼'에서 저장된 주소와 현재 접속 상태를 확인합니다.
기본 주소 안내 페이지는 https://xn--vg1b79zgsf1sj.com/입니다. '도메인 설정 → 뉴토끼 → 주소 안내 페이지 설정'에서 변경할 수 있습니다.
B 접속 확인은 항상 저장된 안내 페이지의 첫 번째 hud-url(최신 주소)을 읽는 것부터 시작합니다. 뒤쪽 구버전 주소는 선택하지 않습니다.
일반 연결 실패이면 그 번호에 +1, +2, +3을 순서대로 적용합니다. 브라우저 검증을 요청한 주소에서는 번호 탐색을 중단합니다. 정상 응답을 확인하면 즉시 멈추고 B 주소로 저장합니다.
예: hud-url이 toki34.com이면 toki34.com, toki35.com, toki36.com, toki37.com 순서로 확인합니다.
HTTP 403 등 서버 오류와 주소별 시도/성공/실패는 B 주소 확인 기록에 표시합니다. 전부 실패하면 기존 B 주소를 유지합니다.
'시작할 때 B 주소 자동 확인'은 기본으로 켜져 있으며 A의 자동 확인 설정과 별도로 저장합니다. 'B 접속 확인'으로 수동 검사할 수도 있습니다.
Cloudflare가 브라우저 검증을 요청하면 일반 오류와 구분하여 '검증 필요'로 표시하고 +1/+2/+3 탐색을 중단합니다.
자동 확인은 전용 Chrome의 숨김 페이지에서 진행합니다. 준비용 빈 창은 최소화 상태에서 즉시 정리합니다.
페이지 이동이나 정보 읽기가 일시적으로 늦어져도 같은 접속을 최대 60초 동안 확인합니다. 시간 초과만 발생한 경우에는 검증 필요가 아닌 접속 실패로 표시합니다.
보안검증을 감지한 시점부터 자동 인증을 최대 30초 기다립니다. 일반 응답의 60초와 직접 인증의 최대 3분은 별도로 적용합니다.
도메인 설정에서 현재 주소 조회, Chrome 준비, 사이트 응답, 자동 인증의 경과/남은 시간, 직접 인증 필요, 홈페이지 확인 및 주소 저장 결과를 구분해 보여줍니다.
자동 인증 중에는 검증 버튼이 비활성 상태이며, 30초가 지나도 검증이 남으면 버튼을 활성화합니다. Chrome 창은 버튼을 누를 때 엽니다.
홈페이지 연결 성공 뒤에도 소설 본문에서는 추가 인증이 필요할 수 있습니다.
검증이 남으면 '브라우저 검증 열기' 버튼이 활성화됩니다.
브라우저 응답 이후 페이지 판별이나 HTTP 오류가 발생한 경우에도 다른 번호로 이동하지 않습니다.
홈페이지의 문서 제목을 사용하므로 로그인·회원가입 아이콘 제목 때문에 정상 홈페이지를 실패로 판정하지 않습니다.
‘브라우저 검증 열기’ 버튼을 누를 때만 실제 B 주소의 전용 Chrome 창을 엽니다. 필요한 검증을 직접 완료하세요. 최대 3분 동안 확인하며 홈페이지가 열리면 자동으로 주소를 저장합니다.
3분이 지난 뒤 검증을 완료했다면 'B 접속 확인'을 다시 누르세요.
정상 확인한 세션은 같은 PC의 다음 실행에서 재사용합니다. 서버 정책·IP 변경·만료에 따라 검증이 다시 필요할 수 있습니다.
다른 사람에게는 ZIP 전체를 전달하세요. 각 PC의 Chrome 설치 경로를 자동 탐색하고 사용자별 전용 프로필을 따로 만듭니다.
전용 프로필: %LOCALAPPDATA%\TVMON-Download-Manager\text-browser
다른 PC의 인증 상태를 복사하지 않으며 기존 개인 Chrome 프로필도 사용하지 않습니다. 각 PC에서는 최초 검증이 필요할 수 있습니다.
Chrome을 찾지 못하면 설치 상태를 확인하라는 메시지를 표시합니다. 설치 후 B 접속 확인을 다시 누르세요.
프로그램을 종료하면 프로그램이 실행한 전용 Chrome만 종료합니다. 기존 Chrome 창은 건드리지 않습니다.

B 접속 로그
자동 확인과 직접 검증의 시작/결과, 접속 주소, HTTP 상태, Chrome 응답 시간 및 오류 단계, 주소 저장 결과를 파일에 누적 기록합니다.
로그 파일: 실행 파일 옆 data\text-domain.log
1MB 이상 쌓이면 text-domain.previous.log로 옮기고 새 파일에 기록합니다. 이전 파일은 한 개만 보관합니다.
쿠키·응답 본문·HTTP 헤더는 기록하지 않으며 주소의 쿼리와 프래그먼트는 제외합니다.
오류가 반복되면 로그 파일에서 해당 시간의 chrome_timeout 또는 check_error 기록으로 지연된 단계를 확인할 수 있습니다.

B의 저장 주소는 jobs.json의 text_domain, 자동 확인 설정은 auto_text_domain 항목입니다.
A의 주소 순서, 검색 기록과 영상 다운로드 작업은 그대로 유지합니다.
소설 사이트는 주소 확인, 작품 검색, 다운로드 가능한 회차 목록, TXT 저장과 전체 ZIP 저장을 지원합니다.

일시정지와 이어받기
목록에서 작업을 선택하고 '일시정지'를 누릅니다.
완료한 조각을 보관하며, 아직 완료되지 않은 조각은 재개할 때 다시 받습니다.
'시작 / 이어받기'를 누르면 보관한 조각의 상태를 확인하고 나머지만 받습니다.
프로그램을 닫으면 진행 작업을 정리한 뒤 종료합니다. 다시 실행하면 목록이 복원됩니다.
다시 실행한 뒤에는 원하는 작업을 선택하고 '시작 / 이어받기'를 눌러 주세요.
Ctrl+A로 현재 목록을 모두 선택할 수 있고, Ctrl/Shift로 여러 작업을 선택할 수 있습니다.
목록에서 Space 키는 선택한 진행 작업의 일시정지 또는 이어받기로 작동합니다.

화면 읽기
위쪽 목록: 영상 제목, 상태, 진행률, 저장 용량, 실제 수신 속도, 남은 시간.
아래 왼쪽: 1~8번 작업의 조각 번호, 상태, 수신량, 속도. 작업 행을 선택하면 서버를 표시합니다.
아래 오른쪽: 회색은 대기, 파란색은 수신 중, 초록색은 저장 완료, 주황색은 오류입니다.
영상 조각 지도 제목에 해당 영상의 전체 영상 서버 수를 표시합니다. 조각 주소의 서로 다른 서버 도메인 개수이며 동시 작업 수와는 별개입니다.
서버 정보 버튼을 누르거나 영상 서버 탭을 선택하면 해당 영상의 전체 서버 주소와 서버별 조각 수를 확인할 수 있습니다.
영상 정보를 읽으면 서버 개수와 목록을 저장하며 일시정지, 완료, 프로그램 재시작 후에도 유지합니다. 기존 작업은 정보를 다시 읽기 전까지 확인 전으로 표시합니다.
작업 기록 탭: 시작, 일시정지, 재개, 완료 및 오류 메시지.
다운로드 목록은 화면 중앙을 넓게 사용합니다. 하단에는 선택한 작업의 제목·상태·저장량을 요약하며, 다운로드 중인 항목은 진행률도 표시합니다.
하단의 상세 보기를 누르면 별도 창에서 진행 상태, 작업 기록, 영상 서버를 확인합니다. 새로 열 때마다 '진행 상태' 탭이 먼저 표시됩니다. 상세 창을 닫아도 다운로드는 계속됩니다.
목록 위 전체/진행 중/대기/완료/일시정지/오류 버튼으로 필터링합니다. 목록 검색 입력칸에서는 작업 제목을 검색합니다.

파일 관리
완료 항목의 '재생' 메뉴는 Windows에 연결된 영상 재생 프로그램으로 TS 영상을 엽니다.
'목록에서 제거'는 확인 후 선택한 목록 항목과 이어받기 조각을 정리합니다. 완료한 영상은 보관합니다.
저장 폴더의 .tvmon-resume-... 폴더에는 해당 작업의 이어받기 조각과 기록이 있습니다.
병합이 끝나면 조각을 정리하고 작은 완료 기록만 남깁니다.
작업 목록은 실행 파일 옆 data\jobs.json에 저장합니다.
상단 저장 폴더 변경은 새로 추가하는 작업에 적용됩니다. 기존 작업은 원래 폴더에서 이어받습니다.

참고
이어받기는 완료한 영상 조각 단위입니다.
영상의 조각 구성이나 암호화 정보가 바뀌면 서로 다른 내용을 섞지 않도록 재개를 중단합니다.
병합 중에는 조각과 최종 파일을 함께 보관하므로 영상 크기의 약 2배 공간이 필요합니다.
일시정지나 종료 시 현재 통신을 정리하는 동안 잠시 기다릴 수 있습니다.
최소 창 크기는 960×850입니다. 기본 크기에서 8개 작업을 모두 볼 수 있습니다.

데이터 보관 위치
실행 파일 옆 data 폴더에 jobs.json, jobs.lock, text-domain.log와 회전 로그 text-domain.previous.log를 보관합니다.
최근 검색어, 다운로드 대기열, 접속 주소와 설정은 data/jobs.json에 저장합니다.
처음 실행할 때 data/jobs.json이 없으면 기존 Windows 사용자 폴더의 기록과 접속 로그를 복사합니다. 기존 원본은 삭제하지 않습니다.
이미 data/jobs.json이 있으면 해당 기록을 우선 사용하며 이전 위치의 기록으로 덮어쓰지 않습니다.
이전 버전이 실행 중이면 먼저 종료해야 기록을 이전할 수 있습니다.
다른 PC로 기록까지 옮기려면 data 폴더도 함께 복사하세요. 저장 폴더와 완료 파일 경로는 기존 값을 유지하므로 다른 PC에서 경로를 확인하세요.
실행 파일이 있는 폴더에 쓰기 권한이 필요합니다.
Chrome 인증용 text-browser 프로필은 현재 PC의 기존 LOCALAPPDATA 위치를 사용합니다. 다른 PC에서는 B 사이트 인증이 다시 필요할 수 있습니다.
배포 ZIP에는 개인 작업 목록이나 접속 로그를 포함하지 않습니다.

도메인 설정 화면
왼쪽에서 TVWIKI 또는 뉴토끼를 선택합니다. 현재 주소, 자동 확인 설정, 마지막 확인 결과를 순서대로 표시합니다.
접속 확인 전에는 정상 연결로 표시하지 않습니다. 확인 중, 정상 연결, 확인 필요, 인증 필요를 구분합니다.
접속 문제 해결과 자세한 접속 기록은 눌러 펼칠 수 있으며 한 번에 한 영역을 표시합니다. 인증이 필요하면 문제 해결 영역이 자동으로 열립니다.
주소 확인과 저장, 브라우저 검증 동작은 기존 기능을 사용합니다.

화면 표시 개선
선택한 상단 탭은 더 큰 글자와 여백, 파란 배경으로 표시합니다.
목록과 작업 기록의 스크롤바는 내용이 화면을 넘을 때만 표시하고, 필터·작업 삭제·창 크기 변경에 따라 자동으로 숨깁니다.
도메인 설정 왼쪽의 TVWIKI·뉴토끼 이름 아래에도 각 사이트의 확인 전, 확인 중, 정상 연결, 확인 필요, 인증 필요, 확인 중단 상태를 표시합니다. 상태는 마지막 접속 확인 결과이며 실시간 상시 감시는 아닙니다.

시간 표시와 접속 상태
남은 시간 열은 실행 환경의 글자 폭을 기준으로 너비를 확보하고, 파일 제목 열이 남는 공간에 맞춰 늘어납니다. 오른쪽에 여백을 두어 스크롤바 표시 유무와 관계없이 제목과 시간이 보이도록 했습니다.
도메인 설정은 사이트명과 접속 결과 배지를 나눠 표시합니다. 정상 연결은 초록색, 연결 또는 주소 저장 실패·인증 필요는 빨간색, 확인 전·중단은 회색, 확인 중은 파란색입니다. 파란 테두리는 현재 선택한 사이트를 뜻합니다.

오류 시 자동 재시도
다운로드 탭 오른쪽의 '오류 시 자동 재시도' (보조 설명: '30초 간격')는 기본으로 켜져 있으며 변경한 설정을 data/jobs.json에 저장합니다.
실행 중인 대기열에서 오류로 끝난 작업은 30초 후 다시 시도합니다. 계속 실패해도 같은 간격으로 반복하며 정상 대기 작업을 먼저 처리합니다.
영상은 이미 받은 조각을 재사용합니다. 전체 ZIP의 기존 내부 3회 재시도는 유지하고, 최종 오류 뒤 계속 재시도 여부에 이 옵션을 적용합니다.
옵션을 끄거나 해당 작업을 일시정지하면 계속 재시도를 멈춥니다. 직접 브라우저 인증이 필요한 작업은 자동 재시도하지 않습니다.
프로그램을 다시 열 때 대기열이 자동 시작되지는 않습니다. 시작/이어받기를 눌러 실행하세요.

상단 사이트 연결 표시
세 탭 오른쪽 끝에 TVWIKI와 뉴토끼의 접속 상태를 각각 표시합니다. 어느 탭에서도 색상과 글자로 확인할 수 있습니다.
확인 전, 확인 중, 자동 인증 중, 직접 인증 중, 인증 필요, 정상 연결, 확인 필요를 구분합니다.
이 표시는 마지막 접속 확인 상태이며 사이트를 계속 감시하는 기능은 아닙니다.

다운로드 인증 필요 표시
오류 시 자동 재시도는 주변과 같은 배경에 큰 파란 체크 표시를 사용하고, 30초 간격은 작은 보조 설명으로 표시합니다.
브라우저 인증 때문에 멈춘 다운로드는 상태 열에 '인증 필요'로 표시하고 행을 연한 붉은 배경으로 강조합니다. 일반 오류와 구분합니다.
다운로드 목록 위에 인증 대기 작업 수와 '브라우저 인증 열기' 버튼이 나타납니다. 현재 필터나 검색에 작업이 가려져 있어도 안내는 보입니다.
버튼을 누르면 선택한 인증 대기 회차를 엽니다. 선택한 작업이 인증 대상이 아니면 첫 인증 대기 회차를 선택하고 엽니다. 인증 후 이어서 다운로드합니다.
전체 ZIP은 포함된 회차가 인증을 기다릴 때 같은 상태로 표시합니다. ZIP 행에서 인증 버튼을 눌러 해당 회차를 열 수 있습니다.
인증 안내의 작업 수는 실제 인증 대기 회차 기준이며 ZIP 행을 중복해서 세지 않습니다. 프로그램을 다시 열어도 미해결 인증 상태를 표시합니다.
인증이 완료되면 해당 표시와 안내가 사라집니다. Chrome 창은 인증 버튼을 직접 눌렀을 때만 엽니다.

뉴토끼 주소 안내 페이지 설정
도메인 설정에서 뉴토끼를 선택하고 '주소 안내 페이지 설정'을 펼치세요.
안내 URL을 입력한 뒤 '저장' 버튼 또는 Enter로 저장하고, '접속 확인'을 누르면 새 안내 페이지에서 주소를 찾습니다.
입력 중인 값은 저장해야 적용합니다. 저장된 URL은 프로그램을 다시 열 때의 자동 확인과 직접 브라우저 검증에도 사용합니다.
HTTPS 주소와 페이지 경로·쿼리를 지원합니다. 스킴 없이 입력한 일반 도메인에는 https://를 붙이고, 페이지 내 위치(# 뒤)는 제외합니다.
올바르지 않은 URL 또는 파일 저장 실패 때는 기존 안내 URL을 유지합니다. 접속 확인 중에는 저장 버튼을 비활성화합니다.
설정은 실행 파일 옆 data/jobs.json의 text_domain_guide_url에 저장합니다. 기존 파일에 이 항목이 없으면 종전 기본 안내 주소를 사용합니다.
안내 URL을 바꿔도 사용 중인 사이트 주소는 유지하며, 새 접속 확인에 성공하면 갱신합니다.
안내 페이지는 기존과 같이 첫 번째 class="hud-url"에 현재 주소가 있고 일치하는 연결 링크가 있는 형식을 지원합니다.
안내 페이지의 HTML 구조가 달라지면 주소 추출 코드도 별도로 수정해야 합니다. 다른 도메인으로 이동하는 안내 URL은 확인된 최종 안내 URL로 직접 설정하세요.
TVWIKI의 안내 URL은 '도메인 설정 → TVWIKI → 주소 안내 페이지 설정'에서 별도로 관리합니다. 다운로드·재시도·인증 대기 동작은 그대로 유지합니다.


P2P + HTTP 영상 다운로드
지원하는 영상에서는 설치된 Chrome을 별도 백그라운드 수신 작업자로 실행해 P2P로 조각을 받습니다.
P2P 피어 검색은 백그라운드에서 진행하며 HTTP 시작을 기다리게 하지 않습니다. 해당 조각을 실제로 P2P 수신 중일 때만 최대 2초 기다립니다.
HTTP 응답 대기나 수신 중 같은 조각이 P2P로 준비되면 HTTP 요청을 정리하고 검증된 P2P 조각으로 전환합니다.
P2P 조각도 복호화와 MPEG-TS 검사를 거쳐 저장합니다. 검사에 실패하면 해당 조각을 HTTP로 다시 받습니다.
기존 일시정지, 이어받기, 완료 조각 보관과 최종 파일 합치기를 그대로 사용합니다.
영상 조각 지도 위에 P2P 수신량, 연결 피어 수, HTTP 병행 상태를 표시합니다.
현재 구현은 P2P 수신만 사용하며, 다른 피어로의 조각 업로드는 꺼져 있습니다.
다운로드 완료·일시정지·종료 때 전용 Chrome 연결을 닫고 임시 프로필을 정리합니다. 평소 사용하는 Chrome 창과 프로필은 사용하지 않습니다.
P2P 속도는 다른 시청자가 가진 조각과 연결 상태에 따라 달라집니다. 영상 전체가 같은 속도로 내려받아지는 것은 아닙니다.


HTTP · P2P 상세 진행
상세 진행의 8개 행은 조각을 검증·저장하는 처리 작업입니다. 서버 전용 연결 8개를 의미하지 않습니다.
방식 열에서 HTTP, P2P, P2P 확인을 구분합니다. P2P 대기는 아직 HTTP 요청을 시작하지 않은 상태입니다.
HTTP 수신 중 P2P 조각이 준비되면 P2P로 전환할 수 있으며, 전환 결과는 작업 기록에 표시됩니다.
행을 선택하면 현재 방식, 전환 여부와 HTTP 서버를 확인할 수 있습니다. P2P 행의 HTTP 속도는 표시하지 않습니다.
HTTP · P2P 상세 탭에서 각각의 이번 실행 수신량·속도, 저장 완료 조각 수, 피어 수와 미리받기 목록을 확인합니다.
수신량은 중복·재시도 수신을 포함합니다. 저장 완료 조각은 이어받기 기록까지 포함하므로 두 값의 의미가 다릅니다.
P2P는 별도로 최대 5개 조각을 동시에 미리 받으며, 목록에서 수신·전달 중과 검증·저장 대기를 구분합니다.
지도에서 HTTP 요청/수신은 파랑, HTTP 저장 완료는 초록, P2P 수신/검증은 연보라, P2P 저장 완료는 진보라입니다.
같은 조각을 HTTP와 P2P가 동시에 받으면 두 색을 함께 표시합니다. 큰 영상에서는 한 칸에 여러 조각이 포함됩니다.
방식 기록이 없는 이전 저장 조각은 회색의 '방식 미기록'으로 표시합니다. 과거 P2P 조각을 서버 조각으로 추정하지 않습니다.
새로 저장한 조각의 HTTP/P2P 구분은 프로그램을 다시 열어도 유지됩니다. 실시간 수신량과 속도는 실행마다 다시 계산합니다.


준비된 조각 우선 처리와 상세 로그
P2P 미리받기 대상은 아직 저장하지 않은 다음 32개 조각입니다. 앞 조각이 늦어져도 뒤에서 완료된 조각을 빼고 새 대상을 채웁니다.
이미 준비된 P2P 조각을 먼저 저장하며, HTTP는 가능한 한 P2P 수신 중인 조각과 겹치지 않게 배정합니다.
완료 순서와 관계없이 조각별 검증, 이어받기 해시 확인, 원래 순서로 합치기를 유지합니다.
상세 진행 → 작업 기록 → 상세 로그 폴더 열기에서 실행별 JSONL 로그를 확인하세요.
로그 위치: 실행 파일 옆 data\transfer-logs
조각 배정, HTTP 요청·첫 수신·오류·재시도, P2P 수신·취소, 전환, 검증·저장과 파일 해시를 기록합니다.
약 2초 간격으로 속도·수신량·피어 수·작업별 상태를 기록하며, 중단 후 재개하면 새 파일을 만듭니다.
로그는 종료 후에도 남습니다. 새 다운로드부터 기록하므로 이전 실행의 상세 기록을 소급 생성하지 않습니다.
서명된 영상 주소, 쿠키, 인증 헤더와 복호화 키는 기록하지 않습니다. 작품명과 공개 회차 주소는 기록합니다.
화면 수신량에는 중단된 전송과 중복 수신이 포함되므로 최종 저장 용량보다 클 수 있습니다.
로그 쓰기 실패 시 작업 기록에 알리고 다운로드는 계속합니다. 오래된 상세 로그는 자동 삭제하지 않습니다.


저장 처리 개선과 P2P 무수신 원인 진단
서로 다른 조각 파일은 병렬로 저장합니다. 같은 조각에 여러 작업이 접근할 때는 쓰기 순서를 유지합니다.
완료 표시는 조각 파일과 이어받기 기록을 모두 디스크에 확정한 뒤 진행하며, 조각별 해시 검증과 원래 순서의 병합을 유지합니다.
상세 로그의 segment_storage에는 쓰기 대기, 조각 저장·디스크 확정, 이어받기 기록 갱신 시간을 각각 남깁니다.
merge_write, merge_sync, publication_finish로 최종 병합과 디스크 확정, 완료 기록·임시 조각 정리 시간을 구분합니다.
약 2초 주기의 p2p_diagnostics에는 조각별 피어 보유 수, 해당 조각을 HTTP로 준비 중인 피어 수, 현재 요청 가능한 피어 수와 엔진 요청 대기열 포함 여부를 기록합니다.
엔진 내부 캐시 사용량과 여유, 적용된 미리받기 범위, 기준 조각의 등록 상태도 함께 기록합니다.
not_advertised는 연결된 피어가 해당 조각을 제공 중이라고 알리지 않은 상태입니다. peer_still_loading은 피어도 해당 조각을 받는 중입니다.
peer_busy는 해당 피어 연결로 다른 조각을 받는 중이고, concurrency_limit은 동시 수신 한도에 도달한 상태입니다.
behind_queue_boundary는 등록된 조각이 엔진의 실제 요청 대기열에 포함되지 않은 상태입니다. anchor_not_registered는 엔진 기준 조각이 현재 목록에 없는 상태입니다.
outside_effective_window는 캐시 여유 등을 반영한 현재 수신 범위 밖의 조각입니다. eligible_not_requested는 제공 가능한 피어와 처리 여유가 있는데 아직 요청이 시작되지 않은 상태입니다.
한 번의 순간 기록만으로 지속적인 병목을 단정하지 말고 여러 기록과 실제 수신·저장 결과를 함께 확인하세요.
제공 엔진의 구조가 달라 진단 정보를 읽을 수 없으면 unsupported 또는 error를 남기고 기존 다운로드는 계속합니다.


P2P 요청 대기열과 중복 수신 개선
앞쪽 조각을 제공하는 피어가 없어도, 등록된 다음 미완료 조각 32개 안에서 받을 수 있는 뒤쪽 조각을 계속 찾습니다.
영상 재생 순서를 우선하려고 진행 중인 다른 조각 수신을 취소하지 않으며, P2P 동시 수신 한도 5개와 다운로드 작업 8개는 유지합니다.
HTTP로 받은 조각의 복호화와 검증이 끝나면 디스크 저장을 기다리기 전에 해당 P2P 작업을 종료합니다.
이어받기 완료 기록과 화면의 저장 완료 표시는 기존처럼 파일과 체크포인트 확정 이후에만 갱신합니다.
상세 로그의 p2p_engine.queue_policy가 download_available이면 이 대기열 정책을 사용하는 실행입니다.
엔진 내부 대기열의 구조에 의존하므로 외부 엔진이 바뀌면 호환성을 다시 확인해야 하며, P2P를 사용할 수 없는 동안에도 HTTP 수신은 계속됩니다.


완료 조각의 P2P 엔진 캐시 반납
이미 처리한 조각은 현재 영상의 엔진 캐시에서 제거하고 캐시 사용량을 함께 갱신합니다. 앞쪽 조각이 늦어져도 완료된 뒤쪽 조각 때문에 수신 범위가 줄어드는 상황을 방지합니다.
완료 알림 뒤 늦게 엔진 캐시에 들어온 데이터도 다음 수신 처리 주기에 정리합니다. 미완료 조각과 전달 중인 데이터, 이어받기 파일은 보존합니다.
상세 로그 p2p_engine.cache_policy=release_completed로 적용 여부를 확인할 수 있으며, p2p_diagnostics.cache_released_bytes에 실제 반납한 캐시 바이트 누계를 기록합니다.
디스크 저장 완료와 이어받기 체크포인트 확정 절차는 기존과 같습니다.


이어받기 기록의 묶음 확정
각 조각을 디스크에 저장한 뒤, 동시에 준비된 조각들의 이어받기 기록을 한 번에 확정합니다. 기록을 쓰는 동안 다른 조각의 저장은 계속 진행합니다.
해당 기록의 디스크 동기화와 원자 교체가 완료된 뒤에만 완료로 표시합니다. 기록 확정에 실패한 조각은 완료로 인정하지 않습니다.
기존 이어받기 형식과 조각/최종 파일 해시 검증은 유지합니다. 상세 로그 segment_storage.checkpoint_writer와 checkpoint_parts에서 실제 기록 횟수와 묶음 크기를 확인할 수 있습니다.


HTTP·P2P 중복 수신 조율 및 수신·저장 분리
HTTP 요청 전에 P2P 작업자에게 해당 조각의 배정을 알리고 적용 응답을 확인합니다. P2P 작업자는 HTTP가 맡은 조각의 수신을 시작하지 않으며, 검증된 조각의 완료 통지를 즉시 처리합니다. HTTP 요청이 2초 이상 걸리면 P2P 참여를 다시 허용해 먼저 검증된 데이터를 사용합니다.
수신 작업자와 저장 작업자를 분리합니다. 저장 작업에 넘긴 데이터는 최대 32MiB·16개 조각으로 제한하고, 여유가 없으면 추가 배정을 멈춥니다. 별도로 최대 8개 수신 작업이 진행 또는 저장 인계를 기다릴 수 있으며, 조각별 기존 32MiB 수신 상한을 유지합니다.
완료 표시는 조각과 이어받기 기록의 디스크 확정 후에만 이뤄집니다. 취소 시 실행 중인 저장 처리를 마친 뒤 확정된 조각만 이어받기에 사용합니다. 기존 기록 형식과 해시 검증은 유지합니다.
상세 로그의 http_claim, segment_received, storage_pending, storage_buffered_bytes에서 배정 대기와 저장 대기량을 확인할 수 있습니다.


연결된 피어 IP·국가 확인
다운로드 중인 영상을 선택한 뒤 ‘상세 진행보기’ → ‘연결된 피어’ 탭을 열면 현재 연결된 피어의 IP 주소와 국가를 확인할 수 있습니다. IPv4·IPv6를 지원하고, 연결이 종료된 피어는 목록에서 제거합니다.
IP 확인 중에는 ‘확인 중’, 브라우저가 주소를 공개하지 않으면 ‘미공개’, 국가 조회 실패 시 ‘조회 불가’로 표시합니다. 국가는 접속 IP 기준 추정값이므로 VPN·중계 서버의 국가가 표시될 수 있습니다.
국가 조회를 위해 공개 IP를 HTTPS로 country.is에 전송합니다. 사설·예약 주소는 외부 조회하지 않습니다. IP·국가 목록은 현재 실행의 메모리에만 유지하며 작업 목록과 다운로드 상세 로그에 저장하지 않습니다. 국가 조회는 별도 작업으로 수행되어 영상 다운로드를 기다리게 하지 않습니다.


영상 서버 자동 탐색
기본 영상 서버에서 재생 목록이나 키를 받지 못하면 같은 영상의 S1~S9 서버를 순서대로 확인합니다. 정상 서버를 찾으면 자동으로 다운로드를 시작하며 별도 설정이 필요하지 않습니다.
다른 서버를 선택할 때는 영상 식별자, 재생 목록, 복호화 키와 처음·중간·마지막 조각을 검사합니다. 확인 중에는 일시정지/취소할 수 있습니다.
작업 기록에 확인 중인 서버와 선택 결과가 표시됩니다. 모든 서버가 실패하면 오류를 표시하고 기존 자동 재시도 설정을 따릅니다.
이 기능은 다운로드 시작 시 영상 서버를 선택하는 기능입니다. 다운로드 도중 실패한 조각의 재시도와 이어받기는 기존 방식으로 처리합니다.


TVWIKI 주소 안내 페이지 설정
도메인 설정에서 TVWIKI를 선택하고 '주소 안내 페이지 설정'을 펼치세요.
안내 URL을 입력한 뒤 '저장' 버튼 또는 Enter로 저장합니다. 저장한 값은 프로그램을 다시 열어도 유지됩니다.
접속 확인은 기존처럼 등록된 주소를 먼저 확인하며, 모두 실패하면 저장한 안내 페이지에서 최신 주소를 찾습니다.
기본 안내 URL은 https://tvwikiurl.net/입니다. 기존과 같이 '현재 안내 주소'와 일치하는 연결 링크가 있는 HTTPS 안내 페이지를 지원합니다.
안내 URL의 경로와 쿼리를 지원하며, 다른 사이트로 이동하는 안내 URL은 최종 안내 URL을 직접 설정해야 합니다.
안내 페이지의 형식이 바뀌면 주소 추출 코드도 별도로 확인해야 합니다.
올바르지 않은 URL이나 저장 실패 때는 이전 설정을 유지하며, 접속 확인 중에는 안내 URL 저장을 잠시 막습니다.
안내 URL 변경만으로 사용 중인 접속 주소나 기존 작업 기록이 바뀌지는 않습니다.

도메인 설정 화면의 긴 내용
큰 화면 배율이나 작은 창에서 설정이 길어지면 오른쪽 본문을 휠 또는 세로 스크롤바로 이동할 수 있습니다. 왼쪽 사이트 선택은 고정됩니다.
설정을 펼치거나 Tab으로 항목을 선택하면 해당 항목이 화면 안에 들어오도록 스크롤합니다.
